Postman — тестовая сборка для Windows 10/11 x64 (кросс-сборка mingw)

Файлы:
  postman.exe         — интерфейс на egui (wgpu, DirectX 12)
  postman-gpui.exe    — интерфейс на gpui (DirectX 11)
  postman-worker.exe  — изолированный разбор писем; должен лежать рядом с ними
  VERSION.txt         — коммит, из которого собрано

Демо без сервера (синтетический ящик на 50 000 писем, создаётся при первом запуске):
  postman.exe --demo
  postman-gpui.exe --demo 50000

Что проверить:
  1. Потянуть окно за край и за угол — нет ли чёрных или рваных кадров (Intel!).
  2. Листание списка (колесо, PageDown, j/k), открытие писем, Ctrl+E — поиск.
  3. postman.exe: Ctrl+N/R/Shift+R/F — окно письма; вложения и картинки во втором/первом письме.
  4. postman.exe: каждое десятое письмо (самое верхнее во «Входящих») — приглашение на встречу,
     карточка с кнопками «Принять / Под вопросом / Отклонить».
  5. postman-gpui.exe: Ctrl+2 — календарь, Ctrl+Shift+Q — «Помощник планирования».
  6. Качество текста: полужирный, кириллица, сглаживание.
  7. Замеры: bench.cmd — результат в bench.txt.

Варианты рендера для egui: postman.exe --demo --gpu dx12 | vulkan | gl

Песочница: в строке состояния видно «полная» или «частичная». Полная (AppContainer) требует права чтения
папки для приложений из магазина — один раз запустите sandbox.cmd из этой папки (выдаёт только чтение
этой папки группе ALL APPLICATION PACKAGES), затем перезапустите postman.exe.

SmartScreen предупредит: сборка не подписана. «Подробнее» → «Выполнить в любом случае».
Данные демо: %LOCALAPPDATA%\Postman (можно удалить целиком).
