Postman — тестовая сборка для Windows 10/11 x64: сравнение egui и gpui

Файлы:
  postman.exe         — интерфейс на egui (wgpu, DirectX 12)
  postman-gpui.exe    — интерфейс на gpui (DirectX 11)
  postman-worker.exe  — изолированный разбор писем; должен лежать рядом с ними
  VERSION.txt         — коммит, из которого собрано

Демо без сервера (ящик на 50 000 писем, общий для обеих версий):
  postman.exe --demo
  postman-gpui.exe --demo 50000

1. Замеры. Запустите bench.cmd и не трогайте окна около 5 минут: окна сами листают
   список, меняют размер и ждут в простое. Пришлите получившийся bench.txt.
   В нём: время до первого кадра, интервалы кадров и загрузка CPU при листании и ресайзе,
   память пиковая и в простое, CPU в простое.

2. Ручная проверка — для каждой из трёх: egui DX12 (postman.exe --demo),
   egui Vulkan (postman.exe --demo --gpu vulkan), gpui (postman-gpui.exe --demo 50000):
   а) развернуть и восстановить окно (двойной щелчок по заголовку, Win+стрелки) —
      нет ли чёрного кадра или мерцания;
   б) тянуть за край и за угол — нет ли чёрных или рваных кадров, не отстаёт ли содержимое;
   в) включить РУССКУЮ раскладку и нажать: Ctrl+E (поиск), Ctrl+1 / Ctrl+2 (почта / календарь),
      Ctrl+Q / Ctrl+U (прочитано / не прочитано), клавиши «о» и «л» (это j/k — вниз/вверх по списку);
      в egui ещё Ctrl+N, Ctrl+R, Ctrl+Shift+R, Ctrl+F (окно письма);
   г) чёткость текста: кириллица, полужирный, мелкий шрифт;
   д) общее впечатление: плавность листания колесом и PageDown.
   Удобно ответить таблицей «пункт — egui DX12 / egui Vulkan / gpui — ок или что не так».

Также видно в egui: самое верхнее письмо во «Входящих» — приглашение на встречу
с кнопками «Принять / Под вопросом / Отклонить»; gpui: Ctrl+Shift+Q — «Помощник планирования».

Песочница: в строке состояния видно «полная» или «частичная». Для полной один раз запустите
sandbox.cmd из этой папки (даёт только чтение этой папки группе ALL APPLICATION PACKAGES).

SmartScreen предупредит: сборка не подписана. «Подробнее» → «Выполнить в любом случае».
Данные демо: %LOCALAPPDATA%\Postman (можно удалить целиком).
