# Чего не умеет Stalwart (для issues и своих правок)

Список пробелов и ошибок сервера, найденных на стенде (Stalwart v0.16.27), — чтобы заводить issues у
stalwartlabs или править самим. Подробности и как проверено — `docs/STALWART.md` (номер находки — «п.»).
Новое — сюда же, сразу по находке.

Род: **ошибка** — поведение противоречит спецификации или себе; **нет функции** — нужного нет;
**настройка** — решается конфигурацией сервера, коду не нужно; **[проверить]** — не подтверждено до конца.

| № | Что | Род | Влияние на пользователей | Как обходит Postman | Предложение |
|---|---|---|---|---|---|
| 1 | CalDAV free-busy (POST в outbox) требует сразу `mayReadFreeBusy` **и** `mayReadItems`; JMAP — любое одно (п. 6) | ошибка | Thunderbird и Apple Calendar при шаринге «только занятость» показывают пустую сетку | Postman ходит по JMAP — не затронут | issue + правка в одну строку (`crates/dav/src/calendar/freebusy.rs`, `match_any`) — можем прислать PR |
| 2 | Поля RFC 8984 `replyTo` / `participants.*.sendTo` молча игнорируются: приглашения не уходят, ошибки нет (п. 3) | ошибка (совместимость) | Клиенты по RFC 8984 тихо не рассылают приглашения | Шлём по черновику JMAP Calendars: `organizerCalendarAddress`, `calendarAddress` | issue: принимать оба формата или отвечать ошибкой `invalidProperties` |
| 3 | Занятость коллеги — только после шаринга календаря; нет настройки «все в домене видят занятость всех» (п. 5) | нет функции | Помощник планирования пуст, пока каждый не откроет занятость каждому | Строка «Открыть мою занятость» в календаре; «нет данных» вместо «свободен» | issue (feature): занятость по умолчанию для домена/группы; до того — общий шаринг на группу «все» администратором |
| 4 | Ограничение входящих на получателя: при превышении письма и приглашения (iTIP) молча не доставляются, у отправителя успех (п. 17) | ошибка / настройка | Приглашение «отправлено», но не дошло; без уведомления | Нет (на стороне сервера) | проверить, откладывается ли доставка или теряется; issue: недоставка должна давать DSN/ошибку; порог — настройка |
| 5 | Активен только один Sieve-скрипт, автоответ — тоже скрипт: включение автоответа выключает правила (п. 14, 16) | нет функции | Включил «Нет на месте» — правила перестали работать (в других клиентах) | Скрипт правил Postman подключает автоответ через `include :personal :optional "vacation"` | issue (feature): автоответ независимо от пользовательских скриптов (как неявный `include`) |
| 6 | Сессия объявляет адреса API на внутренний адрес (`http://…:8080`), а не тот, по которому пришёл клиент (п. 1) | настройка [проверить] | Клиенты за прокси/туннелем ходят не туда | Переносим адреса сессии на адрес подключения | задать публичный адрес в настройках сервера (HTTP URL) |
| 7 | Квота загрузки блобов: 1000 файлов или 50 МБ на учётную запись (п. 12) | настройка | Массовый импорт и множество вложений подряд упираются в `overQuota` | Большой ящик заполняется через `Email/set create` | поднять лимит в настройках; [проверить на рабочем сервере] |
| 8 | Справочник: `Principal.name` — логин (адрес), а не ФИО (п. 9) | настройка | В подсказках и контактах адреса вместо имён | Показываем адрес | имена из каталога (OIDC/LDAP) при подключении к нему [проверить] |
| 9 | Папка, открытая только на чтение: `maySetKeywords: true`, хотя право не выдавалось (п. 19) | ошибка [проверить] | Метки в чужой папке «только чтение» может ставить любой | Клиент запрещает правку в папках без права на добавление/удаление | проверить, применяет ли сервер метку; если да — issue |
| 10 | Поиск по тексту «RE: …» ничего не находит (п. 22) | ошибка [проверить] | Поиск по теме с префиксом пуст | Тест ищет без префикса | проверить токенизацию префиксов в полнотекстовом поиске; issue |
| 11 | Сертификат по умолчанию — rcgen, SAN только `localhost` | настройка | Клиент без отключения проверки TLS не подключится | `POSTMAN_INSECURE_TLS=1` только для стенда | сертификат на имя сервера (wildcard — решение владельца) |
| 12 | Квоты пользователей не заданы — `Quota/get` пустой (п. 15) | настройка | Нет предупреждения о заполненности | Строка квоты не показывается | задать квоты на рабочем сервере |
| 13 | Нет серверного механизма «напомнить», «вернуть, если нет ответа», «удалить через N» | нет функции (нет и в JMAP) | Работает только при запущенном клиенте | Планировщик клиента (S5-04) | обсудить: правила Sieve с датами / своё расширение — после MVP |
| 14 | Регистр ключевых слов (метки) — что сервер делает с заглавными (п. 23) | [проверить] | — | Клиент шлёт нижний регистр | проверить |
| 15 | FileNode: виден ли служебный файл (таблица категорий) в «Файлах» пользователя (п. 24) | [проверить] | Пользователь увидит служебный файл | Таблица категорий пока локально | проверить перед переносом таблицы на сервер |
| 16 | Вход через внешний OIDC и автосоздание ящика — не проверены (стенд только с паролями) | [проверить] | — | — | поднять OIDC на стенде |
