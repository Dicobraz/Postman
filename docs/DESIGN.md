# Postman — утверждённый дизайн

Пересмотр ADR 0002, утверждён владельцем 2026-10-20; целиком (с календарём, контактами, задачами и поручениями) —
2026-10-21 (`docs/specs/S0-decisions.md`). Макеты — холст «Postman — дизайн» у владельца (вкладки по блокам).
Пометка «не реализовано — S5-NN» (или S6-NN) — правило утверждено, код ещё не следует ему; задача — в `docs/specs/S5.md`
(`S6.md`). Строки «Сделано в S5-NN» — как реализовано и чем отличается от макета.
Эталон главного окна — «главное окно v2 · быстрые фильтры закладками внизу».

## Главное окно
- Раскладка как у Outlook: рейл модулей | панель папок | список | панель чтения.
- Заголовок окна — только вкладки. Поиск — в командной строке (не конфликтует с вкладками).
- Командная строка вместо ленты: одна строка, одна акцентная кнопка «Новое письмо».
- Ответ — в панели чтения; новое письмо — вкладка, не окно. Без модальных окон; тосты с «Отменить».
- Тёмная тема и компактная плотность (без аватара и превью).

## Фильтры (боковая панель)
- Воронка у «Входящих» переключает панель Папки ↔ Фильтры. Счётчик на воронке — только фильтры панели.
- В режиме фильтров панель — белая карточка; вверху «Где искать: Входящие | Все папки».
- Группы: Состояние (непрочитанные, упоминания, вложения, флаг), Отправитель (внешние), Категория. Быстрые фильтры в панели не дублируются.
- Над списком одна строка: папка или «Все папки», чип фильтров панели (с ×), «N из M», сортировка.
- «Все папки»: результаты группируются по папкам; группы (и группы по датам) сворачиваются.

## Быстрые фильтры
- Закладки поверх нижнего края карточки списка, растут снизу вверх; «×» у правого края с зазором скрывает их (вернуть: Вид → Быстрые фильтры).
- По наведению поверх списка всплывает панель быстрых фильтров, ничего не сдвигая.
- Порядок по срочности: Угрозы → Срок → Ждём → Мне → Истекают. Ширина равная, позиции стабильны, нули бледнеют; включённая — белая с цветной полосой.
- Логика: закладки между собой — ИЛИ; с фильтрами панели — И.
- Отклонено: строка чипов над списком, строка-счётчики, токены в поиске, полоса-индикатор, подписанная полоса.

## Беседы
- По умолчанию — лента без цитат в панели чтения: только новый текст каждого письма, разделители по дням, свои письма справа на светлой подложке; цитаты — переключателем.
- Опции (Настройки → Чтение): «Стопка в панели чтения» и «В списке, как Outlook». Вид можно задать для папки (ПКМ по папке). Ctrl+→/← — по письмам беседы.
- Сделано в S5-05б: стопка — карточки от старых к новым, прочитанные строкой 36 px, последнее, непрочитанные и открытое
  раскрыты, «··· показать цитату» у каждого письма, «N писем · M участников · Развернуть все»; у раскрытого письма —
  «Ответить» и «Переслать»; вложения и приглашение — у открытого письма стопки. «Как Outlook» — голова беседы — самое
  новое письмо папки (стрелка, число писем папки), письма под ней — строки 30 px с линией; ← / → — клавиши
  `attach.prev` / `attach.next` (без открытого просмотра — беседе), Enter — `thread.fold`. В панели — строка
  «Беседа: N писем · ← пред. · след. → · k из N» (N — вся беседа, все папки). Меню папки — один пункт «Вид беседы ▸».
  В списке «как Outlook» клавиши без выделения (Delete, Ctrl+Q) — на строку-письмо, а не на беседу; беседа целиком —
  через выделение и контекстное меню. Поиск — без бесед.

## Строка письма и метки
- Метки (ключевые слова JMAP `keywords`) — в строке отправителя справа; имя сокращается (≥ 60 px), метки обрезаются слева, категория первой. Слева — цветная полоса категории.
- Регистр: с заглавной только первое слово («До чт», «Внешний»).
- Срок впереди — янтарный текст с часами без подложки («До чт»); срок прошёл — плотная янтарная заливка («Просрочено 1 д»).
- «Ждём ответа», «Напомнит», «Исчезнет», «Внешний» — нейтральные серые.

## Цвет
- Кнопки: главное действие — заливка акцентом; второстепенные — тонированные (светлая подложка акцента #EBF3FC, текст #0F548C; тёмная #23364F / #BFDDFF), без рамки. В тёмной теме кнопка никогда не цвета подложки, на которой лежит. Не реализовано — S5-19 (сейчас второстепенные — с рамкой).
- В одном списке нет близких цветов (ΔE2000 ≥ 25). Красный — только безопасность; янтарный — только сроки и подсветка совпадений поиска.
- Палитра категорий — «общие цвета» Fluent 2 (решение владельца 2026-10-21, `docs/specs/S5.md` №5): полоса — `primary` цвета, подложка метки — `tint40` (тёмная тема — `shade30`), текст — `shade30` (тёмная — `tint40`). Цвета ближе ΔE 25 к красному и янтарному категориям не даются.
- Категории: Клиенты — синий (`blue`), Команда — зелёный (`darkGreen`), Тендеры — фиолетовый (`grape`), Пентест — бирюзовый (`lightTeal`), Сервисы — серый (`mink`). Угроза — бледно-красная подложка с тёмно-красным текстом.
- Тёмная тема: яркие цвета приглушены, основной текст #D2D2D2, вторичный #A6A6A6; крупные цветные заливки → тёмные подложки.
- Без пестроты и чрезмерной яркости/контраста; тёмная тема — приглушённые цвета (принцип владельца, 2026-10-21).
- Исключение (владелец, 2026-10-21, PR #60): розовый бренда #E4107F (свободное время, «Настройки → Календарь») в светлой теме ближе ΔE 25 к красному безопасности (≈ 19, в тёмной — ≈ 23,5). Он только у свободного времени в календаре и встрече и никогда не рядом с красным безопасности. Цвет свободного времени — только цвета бренда: розовый #E4107F, синий #3A9BD5, серо-голубой #7A8FA6. Тёмная тема — вариант B макета встречи везде, и во встрече, и в настройках (решение владельца 2026-10-21): рамка #D2569A, подложка #3A1A2A, наведение #4A2135, текст #F0A8CA; синий и серо-голубой — так же приглушённо.

## Новое письмо
- Композер Markdown: ввод Markdown с живым отображением; кнопки панели форматирования вставляют разметку. Отправка — text/plain + text/html через IR.
  Живое отображение — не реализовано — S5-27 (сейчас, S5-06б, — предпросмотр переключателем: Markdown → IR в воркере).
- Подписи полей и кнопки панели — цвет акцента, единый с «Отправить»: светлая #0067C0, тёмная #7DB8E8 / #8CC4F0.
- Проверки перед отправкой; DLP-подсказка (номер карты) — тёмно-красная подложка.

## Вложения
- Лента сразу под шапкой письма; карточки в одну строку 40 px, статус — иконкой.
- Встроенный просмотр (PDF, архив, картинка) без внешних программ; пока открыт просмотр, текст письма скрыт.
- Файл с макросами: красный щиток и тонкая красная полоса; открытие заблокировано, подробности — в карточке безопасности.
- Сделано в S5-07: лента по 4 карточки, «+N» раскрывает; просмотр — панель в области чтения (Esc, ← / →); PDF — страница
  по ширине панели, вниз — прокрутка (листание ‹ ›, без масштаба и печати; S5-07б); картинка — в своём размере, не шире
  панели; кадр — до 2048 px по длинной стороне; архив — только ZIP, оглавление без распаковки;
  «Открыть без макросов» и «Проверено» (антивирус) не сделаны.

## Действия и состояния
- Выделение: чекбоксы на месте аватаров; панель массовых действий вместо заголовка списка; сводка в панели чтения; контекстное меню с подменю категорий.
- «Сообщить о фишинге»: значок — красная маска (#CD605A).
- Офлайн: строка состояния, метка у аккаунта, тонкий баннер. Тосты: стопка ≤ 3 + «+N», предупреждения нейтральные, красный — только ошибки. История уведомлений — панель справа.
- Сделано в S5-08: панель массовых действий — две строки (выбор и кнопки «Прочитано», «Флаг», «Категория ▾», «Срок ▾»,
  «В папку ▾», «Архив», «Удалить»); в сводке — 8 кнопок в два столбца с клавишами реестра (у Postman нет однобуквенных
  E/V/D; клавиши в тексте кнопок противоречат правилу «Хоткеи» — уберёт S5-18); в меню нет «Всегда перемещать от отправителя» и «Заблокировать отправителя»; история уведомлений — за запуск
  (не 7 дней), без кнопки «Открыть журнал» (ошибки — в журнале Windows).

## Настройки
- Вкладка; слева навигация по разделам с поиском.
- Категории: таблица, редактирование на месте, палитра с запретом близких цветов.
- Быстрые фильтры, сроки и жизненный цикл; Чтение (вид беседы, панель чтения справа/снизу/скрыта, внешние картинки не грузятся, предупреждение о несовпадении текста и адреса ссылки, «Боковая панель справа» для приглашения — не реализовано — S5-24); Подписи и шаблоны; Клавиатура (свои сочетания — сделано в S5-09; выбор схемы — не реализовано — S5-17); Календарь (ниже, «Настройки → Календарь»).
- Правила — редактор правил, хранение Sieve на сервере.
- Аккаунты: добавление в 3 шага на месте; пароль — только Диспетчер учётных данных Windows или не хранится; TLS ≥ 1.2, проверка отзыва.
- Первый запуск — добавление аккаунта на месте.

## Палитра команд и поиск
- Ctrl+K: оверлей под командной строкой; группы Команды / Папки / Быстрые фильтры / Письма.
- Поиск в командной строке: «Везде | Текущая папка»; результаты по папкам; подсветка совпадений; чипы «Уточнить».

## Хоткеи
- Не больше одного модификатора. Ctrl + буква или цифра — команды. Без модификатора — навигация и действие над выделенным: стрелки, Enter, Esc, Del, Insert, F2, F3, Home, PgUp/PgDn, Backspace. Alt не используется.
- Исключения схемы Outlook (два модификатора, ради привычки): Ctrl+Shift+R, Ctrl+Shift+Q, Ctrl+Shift+C, Ctrl+Shift+B, Ctrl+Shift+V (переместить); Ctrl+J — взять в работу (общие ящики, не реализовано — S5-28); Shift+F3 — стандарт Windows; Ctrl+Shift+Tab — пара к Ctrl+Tab (решение владельца 2026-10-21).
- Две схемы (Настройки → Клавиатура): «Outlook» по умолчанию и «Одиночные клавиши» (как Gmail: R, A, F, E, C, /…), выключена.
- В тексте кнопок и полей клавиши не пишутся. Показ: подсказка при наведении «Название (клавиша)» и KeyTips — удержание Ctrl 0,4 с показывает плашки с клавишами над всеми кнопками; отпустил — пропали.
- Основное: Ctrl+1…4 модули, Ctrl+E поиск, Ctrl+K палитра, Ctrl+N новое письмо, Ctrl+R / Ctrl+Shift+R / Ctrl+F ответ, Del удалить, Backspace архив, Insert срок, Ctrl+Q/U прочитано. Календарь: Home сегодня, PgUp/PgDn период, 1…4 вид. Встреча: Ctrl+Enter отправить, ←/→ по свободным окнам, Enter выбрать.
- Сделано (реестр `app-gpui/src/commands.rs`, `docs/PARITY.md`; правило — тест `hotkeys_follow_the_one_modifier_rule`,
  S5-16): Ctrl+1…3, Ctrl+E, Ctrl+K, Ctrl+N, Ctrl+R / Ctrl+Shift+R / Ctrl+F, Ctrl+Q/U, Del, Backspace — архив, Insert —
  срок, Ctrl+Shift+V, Ctrl+Shift+Q, Ctrl+Shift+C, F2, F3 / Shift+F3, Ctrl+Enter (письмо и встреча), Ctrl+T — ещё
  вкладка почты (своя папка, фильтры, письмо), Ctrl+Tab / Ctrl+Shift+Tab, Ctrl+W; календарь — PgUp/PgDn, Home;
  1–9 — категория выделенного (решение владельца 2026-10-21 №6, `docs/specs/S5.md`). Alt, J/K, Ctrl+Shift+G,
  Ctrl+Shift+F сняты; флаг и фильтры — без клавиши (кнопка, меню, палитра); ответ на приглашение — кнопками. Ctrl+Shift+P
  (предпросмотр письма) — исключение до S5-27. Свои клавиши — поверх схемы (S5-09), прежние свои переводятся сами
  (`keymap::migrate`, `Prefs::keys_rev`).
- Не реализовано: схема «Одиночные клавиши» и выбор схемы — S5-17 (туда же J/K, A / T / N приглашения, виды
  календаря 1…4 — с видами S5-21); KeyTips и подсказка «Название (клавиша)», клавиши из текста кнопок (сводка
  выделения, карточка приглашения, подсказка «×» вкладки) — S5-18; встреча ←/→, Enter, Ctrl+Shift+B — S5-23;
  Ctrl+J — S5-28; Ctrl+4 — S6.

## Календарь и контакты
- Цвет события — цвет календаря владельца (свой, отдела, каждого коллеги); у событий коллег — имя владельца. Без ответа — пунктир; выбранное — свечение по контуру.
- Статусы участников — заливные кружки со значком по центру: принял — зелёный ✓, под вопросом — синий ?, отклонил — серый ✕, нет ответа — серая точечная заливка; легенда-счётчик над списком.
- Новая встреча — одна форма: поля сверху, сетка занятости ниже; добавленный участник сразу появляется в сетке. «Только общее свободное время» подсвечивает окна, где свободны все; клик ставит встречу. Неизвестная занятость и внешние — заливка с прозрачностью, без штриховки.
- Календарь: переключатель видов над сеткой (правый край по сетке), поиск над панелью события; ответ на приглашение — полоса во всю ширину панели.
- Приглашение в письме: карточка над телом — сверху детали (дата, время, место, организатор, «N из M приняли»), под ними вертикальный календарь дня на всю ширину (свои события серые, приглашение синее, пересечение фиолетовое, подписи видны), ниже в строку кнопки «Принять» (заливка) / «Под вопросом» / «Отклонить» (тонированные). Опция (Настройки → Чтение): «Боковая панель справа» — кнопки столбиком и лента дня в колонке 300 px. Состояния: без ответа, «Вы приняли», «Отменена».
- Контакты: справочник, мои контакты, «Часто пишу»; поиск понимает неверную раскладку; карточка с занятостью на сегодня; запись справочника — только чтение.
- Сделано в S5-11 (#48): рабочая неделя, «Весь день», линия «сейчас», без ответа — пунктир, «под вопросом» — штрих,
  отклонённые скрыты; подробности события с ответом на приглашение и участниками (кружки статусов 20 px);
  встреча — вкладка одной формой с подбором времени и «Только общее свободное время» (щелчок ставит встречу);
  карточка приглашения со всеми состояниями (новое, отвечено, изменено, отменено, устарело) и пересечениями;
  контакты — справочник и мои, поиск в неверной раскладке, карточка с занятостью на сегодня, справочник — только
  чтение. Цвет события сейчас — цвет категории события (`Categories::for_event`), без категории — роль `app.event.*`.
- Не реализовано: цвет календаря владельца, календари коллег и имя владельца — S5-22; виды «День / Неделя /
  Месяц», переключатель видов над сеткой, поиск над панелью события, свечение выбранного, у «нет ответа» —
  точечная заливка (сейчас пунктирный круг), легенда-счётчик над участниками — S5-21; свободные окна цветом
  «Настройки → Календарь» (цвет — S5-20; рамка, свечение — S5-23), заливка с прозрачностью у неизвестной занятости и внешних,
  ←/→ и Enter по окнам — S5-23; раскладка карточки приглашения (сейчас «Ваш день» — справа) и опция
  «Боковая панель справа» — S5-24; «Часто пишу» — S5-25.

## Задачи (Ctrl+4)
- Списки: Входящие, Сегодня (просроченные сверху), Предстоящие, Из почты, Когда-нибудь, Выполненные; проекты с прогрессом, категории в цветах почты.
- Письмо со «Сроком» само становится задачей; выполнение задачи снимает срок у письма.
- Быстрое добавление одной строкой с разбором фразы (дата, #категория, «!»), распознанное — чипами в поле.
- Карточка задачи: ссылка на письмо, срок, напоминание, повтор, проект, «Время в календаре» (блок в ближайшее свободное окно), подзадачи, заметки Markdown.
- Выполнение: зачёркивание и уход в «Выполненные» через 2 с, тост «Отменить». Приоритет — только «!» акцентом.
- Делегирование: «Поручить» в карточке задачи (исполнитель из справочника, наблюдатели по желанию). Слева один пункт «Поручения», над списком вкладки «Я поручил» | «Мне поручили»; на «Я поручил» флажок «Только свои» (снят — ещё и где я наблюдатель).
- Поручение у исполнителя — карточка как приглашение: «Принять» / «Предложить срок» / «Отклонить», затем «В работе» → «Готово — на проверку». У поручившего — лента шагов, «Напомнить», «Принять результат» / «Вернуть с комментарием», «Изменить срок», «Забрать».
