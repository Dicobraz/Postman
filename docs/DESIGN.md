# Postman — утверждённый дизайн

Пересмотр ADR 0002, утверждён владельцем 2026-10-20. Макеты — холст «Postman — дизайн» у владельца (вкладки по блокам).
Эталон главного окна — «главное окно v2 · быстрые фильтры закладками внизу».

## Главное окно
- Раскладка как у Outlook: рейл модулей | панель папок | список | панель чтения.
- Заголовок окна — только вкладки. Поиск — в командной строке (не конфликтует с вкладками).
- Командная строка вместо ленты: одна строка, одна акцентная кнопка «Новое письмо».
- Ответ — в панели чтения; новое письмо — вкладка, не окно. Без модальных окон; тосты с «Отменить».
- Тёмная тема и компактная плотность (без аватара и превью).

## Фильтры (боковая панель)
- Воронка у «Входящих» переключает панель Папки ↔ Фильтры. Счётчик на воронке — только фильтры панели.
- В режиме фильтров панель — белая карточка; вверху «Где искать: Входящие | Все папки».
- Группы: Состояние (непрочитанные, упоминания, вложения, флаг), Отправитель (внешние), Категория. Быстрые фильтры в панели не дублируются.
- Над списком одна строка: папка или «Все папки», чип фильтров панели (с ×), «N из M», сортировка.
- «Все папки»: результаты группируются по папкам; группы (и группы по датам) сворачиваются.

## Быстрые фильтры
- Закладки поверх нижнего края карточки списка, растут снизу вверх; «×» у правого края с зазором скрывает их (вернуть: Вид → Быстрые фильтры).
- По наведению поверх списка всплывает панель быстрых фильтров, ничего не сдвигая.
- Порядок по срочности: Угрозы → Срок → Ждём → Мне → Истекают. Ширина равная, позиции стабильны, нули бледнеют; включённая — белая с цветной полосой.
- Логика: закладки между собой — ИЛИ; с фильтрами панели — И.
- Отклонено: строка чипов над списком, строка-счётчики, токены в поиске, полоса-индикатор, подписанная полоса.

## Беседы
- По умолчанию — лента без цитат в панели чтения: только новый текст каждого письма, разделители по дням, свои письма справа на светлой подложке; цитаты — переключателем.
- Опции (Настройки → Чтение): «Стопка в панели чтения» и «В списке, как Outlook». Вид можно задать для папки (ПКМ по папке). Ctrl+→/← — по письмам беседы.

## Строка письма и метки
- Метки (ключевые слова JMAP `keywords`) — в строке отправителя справа; имя сокращается (≥ 60 px), метки обрезаются слева, категория первой. Слева — цветная полоса категории.
- Регистр: с заглавной только первое слово («До чт», «Внешний»).
- Срок впереди — янтарный текст с часами без подложки («До чт»); срок прошёл — плотная янтарная заливка («Просрочено 1 д»).
- «Ждём ответа», «Напомнит», «Исчезнет», «Внешний» — нейтральные серые.

## Цвет
- В одном списке нет близких цветов (ΔE2000 ≥ 25). Красный — только безопасность; янтарный — только сроки и подсветка совпадений поиска.
- Палитра выровнена по OKLCH: точки и полосы L 0,62 C 0,14, подложки меток L 0,95, текст метки того же оттенка L 0,42.
- Категории: Клиенты — синий, Команда — зелёный, Тендеры — фиолетовый, Пентест — бирюзовый, Сервисы — серый. Угроза — бледно-красная подложка с тёмно-красным текстом.
- Тёмная тема: яркие цвета приглушены, основной текст #D2D2D2, вторичный #A6A6A6; крупные цветные заливки → тёмные подложки.

## Новое письмо
- Композер Markdown: ввод Markdown с живым отображением; кнопки панели форматирования вставляют разметку. Отправка — text/plain + text/html через IR.
- Подписи полей и кнопки панели — цвет акцента, единый с «Отправить»: светлая #0067C0, тёмная #7DB8E8 / #8CC4F0.
- Проверки перед отправкой; DLP-подсказка (номер карты) — тёмно-красная подложка.

## Вложения
- Лента сразу под шапкой письма; карточки в одну строку 40 px, статус — иконкой.
- Встроенный просмотр (PDF, архив, картинка) без внешних программ; пока открыт просмотр, текст письма скрыт.
- Файл с макросами: красный щиток и тонкая красная полоса; открытие заблокировано, подробности — в карточке безопасности.

## Действия и состояния
- Выделение: чекбоксы на месте аватаров; панель массовых действий вместо заголовка списка; сводка в панели чтения; контекстное меню с подменю категорий.
- «Сообщить о фишинге»: значок — красная маска (#CD605A).
- Офлайн: строка состояния, метка у аккаунта, тонкий баннер. Тосты: стопка ≤ 3 + «+N», предупреждения нейтральные, красный — только ошибки. История уведомлений — панель справа.

## Настройки
- Вкладка; слева навигация по разделам с поиском.
- Категории: таблица, редактирование на месте, палитра с запретом близких цветов.
- Быстрые фильтры, сроки и жизненный цикл; Чтение (вид беседы, панель чтения справа/снизу/скрыта, внешние картинки не грузятся, предупреждение о несовпадении текста и адреса ссылки); Подписи и шаблоны; Клавиатура.
- Правила — редактор правил, хранение Sieve на сервере.
- Аккаунты: добавление в 3 шага на месте; пароль — только Диспетчер учётных данных Windows или не хранится; TLS ≥ 1.2, проверка отзыва.
- Первый запуск — добавление аккаунта на месте.

## Палитра команд и поиск
- Ctrl+K: оверлей под командной строкой; группы Команды / Папки / Быстрые фильтры / Письма.
- Поиск в командной строке: «Везде | Текущая папка»; результаты по папкам; подсветка совпадений; чипы «Уточнить».

## Хоткеи
- Не больше одного модификатора. Ctrl + буква или цифра — команды. Без модификатора — навигация и действие над выделенным: стрелки, Enter, Esc, Del, Insert, F2, F3, Home, PgUp/PgDn, Backspace. Alt не используется.
- Исключения схемы Outlook (два модификатора, ради привычки): Ctrl+Shift+R, Ctrl+Shift+Q, Ctrl+Shift+C, Ctrl+Shift+B; Shift+F3 — стандарт Windows.
- Две схемы (Настройки → Клавиатура): «Outlook» по умолчанию и «Одиночные клавиши» (как Gmail: R, A, F, E, C, /…), выключена.
- В тексте кнопок и полей клавиши не пишутся. Показ: подсказка при наведении «Название (клавиша)» и KeyTips — удержание Ctrl 0,4 с показывает плашки с клавишами над всеми кнопками; отпустил — пропали.
- Основное: Ctrl+1…4 модули, Ctrl+E поиск, Ctrl+K палитра, Ctrl+N новое письмо, Ctrl+R / Ctrl+Shift+R / Ctrl+F ответ, Del удалить, Backspace архив, Insert срок, Ctrl+Q/U прочитано. Календарь: Home сегодня, PgUp/PgDn период, 1…4 вид. Встреча: Ctrl+Enter отправить, ←/→ по свободным окнам, Enter выбрать.

## Календарь и контакты (в работе)
- Цвет события — цвет календаря владельца (свой, отдела, каждого коллеги); у событий коллег — имя владельца. Без ответа — пунктир; выбранное — свечение по контуру.
- Статусы участников — заливные кружки со значком по центру: принял — зелёный ✓, под вопросом — синий ?, отклонил — серый ✕, нет ответа — серая точечная заливка; легенда-счётчик над списком.
- Новая встреча — одна форма: поля сверху, сетка занятости ниже; добавленный участник сразу появляется в сетке. «Только общее свободное время» подсвечивает окна, где свободны все; клик ставит встречу. Неизвестная занятость и внешние — заливка с прозрачностью, без штриховки.

## HTML писем
- Свой рендер IR (HANDOFF §3a). «Открыть в браузере» — системный браузер по явному действию; WebView2 не встраиваем.
