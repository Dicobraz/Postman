# ADR 0001. UI на gpui вместо egui

Статус: принято (2026-10-19, владелец) — ворота фазы 0 пройдены (`docs/specs/S1.md`); условно — с 2026-10-18.

⚠ отступление от базиса: базис Pets — egui/eframe на wgpu DX12.

## Причина

Замер на Windows (`docs/UI-SPIKE.md`): gpui держит меньше памяти (88 против 139 МБ), ресайз ровнее
(p99 5,5 против 13,6 мс), текст через DirectWrite — системного качества; у egui шрифты «кривоватые»,
настройкой не лечится. Интерфейс уровня Outlook (календарь, планировщик, абзацы со ссылками) на gpui требует
заметно меньше своего кода.

## Цена

- CPU при листании выше: после S1-03 и S1-06 поток интерфейса на уровне egui (48 против 44,5 % ядра),
  процесс целиком — примерно на 10 п.п. больше. Простой — 0 % после патча VSyncProvider (S1-02).
- Нестабильный API: gpui-kit 0.7.3 = снимок Zed (`gpui-pre`), версию фиксируем.
- Свои патчи в `third_party/` (`docs/PATCHES.md`): шейдеры, кадры по запросу, живой ресайз.

## Откат

Провал ворот, который не лечится патчем, — возврат к egui (`app` готова) по базису.
