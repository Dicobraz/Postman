# ADR 0002. Каркас и раскладка как у classic Outlook

Статус: принято (2026-10-19, владелец).

⚠ отступление от базиса: базис Pets — визуальный язык Windows Fluent (ориентир WinUI Gallery).

## Решение

- Как у Outlook: каркас и раскладка — левая навигация, три панели (папки — список — чтение), шапка письма,
  окно встречи с «Помощником планирования», хоткеи (`docs/HANDOFF.md` §2a).
- По Fluent, как в базисе: цвета (акцент и светлая/тёмная тема из ОС), шрифты (Segoe UI Variable → Segoe UI,
  Cascadia Mono → Consolas, Segoe Fluent Icons), тосты, подтверждения одной строкой без модальных окон.

## Причина

Сотрудник, пересевший с Outlook, не переучивается: находит всё на привычных местах и жмёт привычные клавиши.

`docs/DESIGN.md`. От Outlook остаются раскладка (модули — папки — список — чтение), хоткеи и привычные места
команд. Отличия: лента заменена одной командной строкой; заголовок окна — только вкладки, поиск — в командной
строке; быстрые фильтры закладками под списком и панель фильтров вместо поиска-конструктора; беседа по
умолчанию — лента без цитат (как в Outlook — опцией); новое письмо — вкладка, ответ — в области чтения;
строгие правила цвета (красный — только безопасность, янтарный — только сроки).
