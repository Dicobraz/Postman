# S0. Решения владельца

Источник правды по решениям: выше всех остальных документов. Новое решение — строкой сверху, с датой.

## 2026-10-20. Пересмотр дизайна и состав MVP

Пересмотр дизайна по ADR 0002 выполнен: утверждённые экраны и правила — `docs/DESIGN.md`.

| № | Вопрос | Решение |
|---|---|---|
| 1 | Правила почты (были вне MVP, «через веб-клиент») | В MVP: редактор в «Настройки → Правила», хранение — Sieve на сервере (capability `sieve` есть) [проверить на стенде] |
| 2 | Метки (теги) (были вне MVP) | В MVP: ключевые слова JMAP `keywords`; на них — категории и быстрые фильтры |
| 3 | Композер: только Markdown или rich text (HANDOFF §7) | Markdown: ввод Markdown с живым отображением, панель форматирования вставляет разметку; отправка — text/plain + text/html через IR, как в §3a |
| 4 | HTML-письма | Без изменений (HANDOFF §3a): свой рендер IR; «Открыть в браузере» — системный браузер по явному действию; WebView2 не встраиваем |
| 5 | Протоколы | Основа — Stalwart по JMAP. IMAP/SMTP для внешних ящиков — бэклог после фазы 3, если по коду не тяжело (`mail-parser` уже есть, `mail-send` того же автора, IMAP-клиент [проверить]) |
| 6 | Календарь и контакты в новом дизайне | Рисуются следующим блоком; до утверждения — раскладка ADR 0002 |

## 2026-10-19. Общий код Pets — репозиторий pets, gpui для всех

Интерфейс всех приложений Pets — gpui; egui отвергнут и в общий код не попадает (Урфин остаётся на egui
до своего решения). Общий код — `github.com/Dicobraz/pets` по функциональным подходам: `pets-commands`,
`pets-gpui-windows`, `pets-i18n`, `pets-shell`, `pets-ui`; крейт — только когда есть потребитель;
предметное (почта) — в Postman. Знания — рецепты `pets/docs/recipes/`. Подключение — git-зависимость
с фиксированной ревизией. Подробно — `pets/docs/decisions.md`.

## 2026-10-19. Ворота gpui пройдены

Фаза 0 закрыта (`docs/specs/S1.md`): хоткеи в русской раскладке, простой 0 %, листание (поток
интерфейса на уровне egui, процесс ~+10 п.п.), ресайз и мониторы на Intel, песочница. **gpui —

## 2026-10-19. Расхождения с базисом Pets

| № | Расхождение | Решение |
|---|---|---|
| 1 | Визуальный язык: в ТЗ — classic Outlook, в базисе — Fluent | Каркас и раскладка — как у Outlook, цвета, шрифты и тосты — по Fluent (ADR 0002). Позже отдельно пересмотреть дизайн и упростить: Outlook слишком тяжёлый |
| 2 | Модальный вопрос при закрытии окна письма (egui) | По базису: подтверждение одной строкой в самом окне. В gpui — сразу так |
| 3 | Бюджеты: exe 19–26 МБ при < 15, первый кадр 0,9–1,1 с при < 250 мс, CPU в простое ~2 % при 0 % | Бюджеты базиса не догма: каждый проект считает свои на этапе ТЗ. Бюджеты Postman — `docs/HANDOFF.md` §2c |
| 4 | CI только на Windows, в базисе — Windows, Ubuntu, macOS | Windows — основа, остальные ОС — по запросу. Решения, не завязанные на ОС, учитывают и их: код вне `sys`-модулей кроссплатформенный |
| 5 | Нет инфраструктуры базиса: локализация EN+RU, тосты, единственный экземпляр, журнал Windows | Взять готовое из Урфина в фазе 1, вместе с реестром команд (`docs/PLAN.md` 1.6) |
| 6 | Процесс: ветки, PR на задачу, спеки | По базису со следующей задачи (0.1, хоткеи): задача = ветка `sX/NN-кратко` = один PR, спека — `docs/specs/Sx.md` |

ADR 0001 (gpui вместо egui) — принят условно; окончательно — выше, после ворот фазы 0.
