установка под Windows, контакты и справочник, устойчивость на реальных ящиках, инструкция пользователя.

## S4-01. Сборка Windows

- egui-версия `app` удалена (gpui её догнал, `docs/PLAN.md` фаза 2); слои, CI, документы — без неё.
- Исполняемый файл — `postman.exe` (бинарь пакета `postman-gpui`); в release без консоли (`windows_subsystem`),
  для `--bench`/`--screens` вывод в консоль родителя (агенты читают строки `screen …`, `bench …`).
- Ресурсы exe: значок, версия, манифест (DPI per-monitor v2, длинные пути, UTF-8).
- Архив `Postman-<версия>-windows-x64.zip` в CI: `postman.exe`, `postman-worker.exe`, `README.txt`, `install.ps1`.
- `install.ps1` (без прав администратора): копия в `%LOCALAPPDATA%\Programs\Postman`, право AppContainer на каталог
  (иначе песочница воркера не стартует вне Program Files), ярлык в «Пуск»; `-Uninstall`. Источник журнала Windows —
  отдельный шаг с правами администратора (по желанию).
- Подпись: `signtool` в CI, если задан секрет сертификата (решение 1).

## S4-02. Контакты и справочник

- Раздел «Контакты» (Ctrl+3, `view.contacts`): личные контакты (JMAP ContactCard) и сотрудники (Principals),
  поиск, карточка (имя, адреса, телефоны, организация), «Написать письмо».
- Создать, изменить, удалить личный контакт (`ContactCard/set`); подтверждение удаления — строкой.
- Сотрудники (Principals) — в подсказках адресов окна письма и окна встречи (`AddressBook::add_directory`).
- Демо — контакты из демо-ящика; живой ящик — через синхронизацию; тест стенда на создание и правку карточки.

## S4-03. Стабилизация живого ящика

- Догрузка писем при прокрутке (`Command::LoadMore`), счётчики папок верны.
- Отказ сервера в доступе (401) при сохранённом входе — снова строка входа, пароль из диспетчера — заменить.
- Тексты синхронизации — через Fluent: `postman_core::sync` отдаёт коды и данные (не готовые русские строки).
- Неделя календаря обновляется по push.
- Большой ящик: сценарий заполнения ящика стенда (20–50 тыс. писем, `Email/import`), замеры на живом ящике —
  первая синхронизация, память, CPU в простое и при листании; бюджеты `docs/HANDOFF.md` §2c.

## S4-04. Инструкция пользователя
