# S5. Новый дизайн (по `docs/DESIGN.md`)

Цель — интерфейс по утверждённому дизайну (владелец, 2026-10-20, пересмотр ADR 0002): вкладки вместо окон,
командная строка, тёмная тема и плотность, фильтры и быстрые фильтры, метки и категории на `keywords`, беседы,
композер во вкладке с проверками, вложения со встроенным просмотром, настройки вкладкой, палитра команд. Функции
фазы 2–3 сохраняются, меняется подача. Задача = ветка `s5/NN-кратко` = один PR; макеты — холст владельца
«Postman — дизайн» (в репозиторий не кладём: там реальные имена и адреса), агентам — локальная копия артбордов.

Начинается после S4 (решение владельца 2026-10-20). Проверка — снимки `--screens` в светлой и тёмной теме, тесты,
стенд; руками — владелец по `docs/MANUAL-TESTS.md`.

## Что нужно от протокола и сервера

| Элемент дизайна | JMAP / Stalwart | Статус |
|---|---|---|
| Метки, категории, быстрые фильтры | `keywords` писем (`Email/set`, `Email/query` по `hasKeyword`) | есть в протоколе; клиент — S5 |
| Фильтры панели, «Где искать», «N из M» | `Email/query` filter (from, hasAttachment, keyword, inMailbox) | есть; клиент — S5 |
| Беседы | `threadId`, `Thread/get`, `collapseThreads` | есть; клиент — S5 |
| «Отменить» отправку (тост) | задержка `EmailSubmission` на клиенте или `sendAt` (FUTURERELEASE) | [проверить на стенде] |
| «Отправить позже» | `EmailSubmission` с `sendAt` | [проверить на стенде] |
| «Ждём ответа», «Напомнит» (отложить), «Исчезнет» | `keywords` + свой планировщик клиента; на сервере — нет | только клиент, работает при запущенном Postman |
| Сроки («До чт», «Просрочено») | `keywords` с датой нет в стандарте — своё хранение (ключевое слово + кэш) | решить в S5-04 |
| Правила | `sieve` (S4-07) | S4 |
| «Сообщить о фишинге» | пересылка как вложение на адрес службы ИБ (настройка) | клиент |
| DLP-подсказка, «упомянуто вложение» | проверки на клиенте перед отправкой | клиент |
| Метка «Конфиденциально» (шифрование вложений) | вне JMAP; PGP/S-MIME — вне MVP (HANDOFF) | только метка, без шифрования — [решение владельца] |
| Встроенный просмотр PDF/архивов | разбор чужих данных — только в воркере-песочнице | клиент + воркер |

## Решения для владельца

| № | Вопрос | Рекомендация |
|---|---|---|
| 1 | Метка «Конфиденциально» на макете шифрует вложения | Пока только метка (ключевое слово), без шифрования; шифрование — вместе с PGP/S-MIME, вне MVP |
| 2 | «Напомнит», «Ждём ответа», «Исчезнет» работают, только когда Postman запущен | Да, для MVP; серверный вариант — правила Sieve или планировщик позже |
| 3 | Блок «Календарь и контакты» на холсте помечен ● (не утверждён) | S5-11 — после утверждения; до того календарь и контакты фазы 2–3 |
