# S5-12 Ф2. S/MIME: расшифровка входящих

Статус: ⏳

Демо-ящик (`postman.exe` без входа) — шаги 1–6; живой ящик со своим сертификатом шифрования в `CurrentUser\My` — 7–9.

1. «Входящие»: письма «Конфиденциально: условия сделки» (Петров Иван), «Пароли к тестовому стенду» (Служба ИБ) и
   «Конфиденциально: штатное расписание» (Сидоров Игорь) — в строке замок вместо скрепки, вместо превью —
   «Зашифрованное письмо».
2. Откройте «Конфиденциально: условия сделки»: на миг «Расшифровка…», затем текст письма; в шапке — «Зашифровано» и
   «Подписано». Щелчок по значку — карточка: первая строка «Шифрование: AES-256-CBC», ниже — подписант Петров Иван,
   корпоративный УЦ, «отзыв не проверялся (демо-ящик)».
3. Вложение «Условия сделки.pdf» в ленте: просмотр открывается; «Сохранить как» сохраняет файл; «Открыть» —
   сообщение «Расшифрованное вложение не открывается из временной папки — сохраните его». `smime.p7m` в ленте нет.
4. «Пароли к тестовому стенду»: вместо текста — серая строка «Письмо зашифровано не для вас: нет ключа к
   сертификату Корпоративный УЦ (демо), № 7701».
5. «Конфиденциально: штатное расписание»: красная строка «Письмо повреждено: проверка целостности не прошла».
6. Поиск по слову «скидка» (из текста первого письма) это письмо не находит.
7. Живой ящик: письмо, зашифрованное вам в Outlook (AES-256, ваш сертификат RSA), открывается; если в письме
   подпись — «Подписано», карточка как у подписанных.
8. Ключ на смарт-карте или с запросом PIN: строка «Нужен PIN смарт-карты · Ввести» → «Ввести» → системное окно PIN
   → письмо открывается. Вынутая карта — «Смарт-карта не вставлена · Повторить».
9. Закройте и снова откройте то же письмо в течение сеанса — PIN второй раз не спрашивается; после перезапуска
   Postman — спрашивается. В `%LOCALAPPDATA%\Postman` нет файлов с текстом письма.
10. Письмо, зашифрованное по ГОСТ (от контрагента с КриптоПро), на компьютере без СКЗИ: строка «Письмо зашифровано
    по ГОСТ: нужно сертифицированное СКЗИ…». С КриптоПро CSP и своим сертификатом ГОСТ — письмо открывается
    [проверить: СКЗИ на стенде нет].
11. Тёмная тема (шаги 2, 4, 5): строки и значки читаются, красная — только у повреждённого.
