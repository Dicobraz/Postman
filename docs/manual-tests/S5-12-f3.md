# S5-12 Ф3. S/MIME: подпись исходящих

Статус: ⏳

Живой ящик; в `CurrentUser\My` — свой сертификат для подписи почты (адрес — как в «От»). Демо — только шаги 1 и 6.

1. Демо: новое письмо — в строке над текстом кнопка «Подписать» (значок сертификата), выключена: в демо своего
   сертификата нет. «Безопасность» → «Подписывать все письма» — включено.
2. Живой ящик с сертификатом: новое письмо — «Подписать» включено. Отправьте письмо коллеге с вложением.
3. У получателя в Outlook — «Подписано», в Thunderbird — значок подписи; в Postman у получателя — «Подписано», карточка
   с вашим сертификатом.
4. Ключ на смарт-карте с PIN: отправка без карты — письмо остаётся во вкладке, строка «Не подписано: смарт-карта не
   найдена…»; «Подписать» снять — письмо уходит без подписи.
5. «От» — адрес без сертификата (общий ящик) с включённым «Подписать»: строка «Не подписано: нет сертификата подписи
   для … · снимите «Подписать»».
6. «Подписывать все письма» выключить — новое письмо открывается с выключенным «Подписать».
7. Сертификат ГОСТ без СКЗИ: строка «Не подписано: сертификат ГОСТ, нужно сертифицированное СКЗИ…». С КриптоПро CSP —
   письмо подписано, у получателя с КриптоПро — «Подписано» [проверить: СКЗИ на стенде нет].
